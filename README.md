# AttendX Test Scripts

## Objective
This repository contains sample automated tests for the
AttendX student attendance application.

## Test Scripts

### 1. login_test.py
Tests valid login, invalid password, and invalid username.

### 2. attendance_marking_test.py
Tests marking students present or absent, invalid student IDs,
and invalid attendance statuses.

## Requirements
- Python 3.x
- Git

## How to Run

Run the login tests:

    python login_test.py

Run the attendance tests:

    python attendance_marking_test.py
